# 醒图素材采集方案汇报

完整离线演示快照，更新于 2026-10-13。包含两种技术方案、100 个 Magic Layers 样本、9 个安卓样本，以及内嵌的 2,357 张展示预览图。

## 在新电脑打开

1. 克隆本仓库，或在 GitHub 点击 **Code → Download ZIP** 并解压。
2. 双击 `index.html`，进入原来的安卓样本 `7523192271907392830`。
3. 左侧可以切换全部样本与技术方案。

不需要安装 Python、Node、模拟器或模型；浏览过程不需要联网。也可以直接双击 `醒图素材采集方案汇报.html`。

```bash
git clone https://github.com/littlesun0727/xingtu-methods-report.git
```

本仓库为私有仓库，首次克隆或下载需要有权限的 GitHub 登录。HTML 文件约 87.5MiB，图片已经包含在文件中，不需要额外下载素材目录。

## 内容范围

保留样本搜索、技术方案、原图与合成图切换、图层显隐、单层查看、缩放及 hash 路由。图像为原汇报采用的展示预览；这里不包含重新采集工具及原始训练数据。
